# 롤러코스터 설계 시뮬레이터 3D

중3 과학 **역학적 에너지 전환과 보존** 단원의 "롤러코스터 설계하기" 수행평가용 프로그램입니다.
3D 놀이공원에서 코스를 직접 설계하고, 손님을 태워 운행하면서 설계가 실제로 작동하는지와 안전한지를 확인합니다.

## 실행 방법

설치할 것은 없습니다. `index.html` 파일을 내려받아 크롬·엣지·사파리 같은 웹 브라우저로 열면 됩니다.
3D 엔진(three.js)을 인터넷에서 불러오므로 **인터넷 연결이 필요합니다.**

- `index.html` : 3D 버전 (기본)
- `2d.html` : 옆에서 본 2D 설계도 버전 (인터넷 없이도 동작)

## 할 수 있는 것

| 기능 | 설명 |
| --- | --- |
| 3D 코스 설계 | 흰 점을 끌면 코스가 옆으로 움직이고, 빨간 화살표를 끌면 높이가 바뀝니다. 점 추가·삭제, 루프 넣기, 구간 종류(일반 레일 · 체인 리프트 · 자석 브레이크) 지정. 코스는 자동으로 승강장으로 돌아오는 순환 코스가 됩니다. |
| 높이 단면도 | 출발부터 거리에 따른 높이를 펼쳐 보여 주고, 점을 위아래로 끌어 높이를 정확하게 맞춥니다. |
| 손님 태우기 | 손님이 줄을 서서 열차에 타고, 운행이 끝나면 내려서 반응 말풍선을 띄우고 걸어 나갑니다. "계속 운행"을 켜면 놀이기구가 계속 돌아갑니다. |
| 시점 | 승강장 · 전체 · 위에서 · 따라가기 · 탑승 시점(맨 앞자리 1인칭, 끌어서 둘러보기) |
| 소리 | 바람 소리, 체인 리프트 딸깍 소리, 브레이크 소리, 손님 비명 (모두 브라우저에서 합성) |
| 계기판 | 속력, 높이, 수직 G, 위치·운동·열·전기 에너지와 "역학적 에너지 = 위치 + 운동" 값, 지금 일어나는 에너지 전환 설명 |
| 에너지 높이선 | 보라색 막대(h + v²/2g). 레일이 이 높이보다 높으면 열차는 넘지 못합니다. |
| 그래프 | 에너지(쌓은 그래프), 속력(이론값과 비교), 수직 G |
| 안전 검토 | 완주, 첫 언덕이 가장 높은지, 최고 속력, G 범위, 루프 꼭대기, 승강장 진입 속력, 지면 높이를 자동 검사하고 문제 위치를 3D 장면에 표시 |
| 계산 노트 | 학생이 먼저 위치 에너지와 속력을 계산해 넣으면 오차를 알려 줍니다. 풀이 과정과 지점별 에너지 표, 보고서용 요약 |
| 미션 | 운행 승인, 계산 박사, 스피드 마스터, 에어타임, 루프 정복 등 9개 도전 과제 |
| 저장 | 설계와 미션 기록은 브라우저에 자동 저장되고, 설계 코드를 복사해서 다른 기기에서 불러올 수 있습니다. |

## 수행평가 기준과의 연결

- **과학적 원리 이해**: 에너지 그래프와 에너지 높이선, 계기판의 "위치 에너지 → 운동 에너지" 같은 전환 설명
- **설계의 타당성**: 안전 탭 (레일 길이·높이·곡선·차량 무게·최고 속력과 안전성)
- **계산 및 추론**: 나의 예측 → 풀이 과정 → 지점별 에너지 표
- **[9과22-02] 전자기 유도**: 자석 브레이크 구간에서 운동 에너지가 전기 에너지로 바뀌는 양을 계산합니다.

## 물리 모델

- g = 9.8 m/s², 위치 에너지의 기준면은 지면(높이 0 m)
- 열차는 질량 중심 한 점으로 계산합니다.
- 마찰을 끄면(기본값) 역학적 에너지가 정확히 보존되어 이론값과 시뮬레이션 값이 같습니다.
- 마찰을 켜면 바퀴 마찰(μ × 수직항력)과 공기 저항이 열에너지로 바뀝니다.
- 승객이 느끼는 힘 = v²κ + g(위쪽 성분), 회전 구간은 설계 속력에 맞춰 레일을 자동으로 기울입니다(뱅크). 수직 G는 약 4 m 구간 평균입니다.
- 안전 기준(수업용): 최고 속력 120 km/h 이하, 수직 G −1.5 ~ +5.0, 루프에서 뒤집혔을 때 G > 0, 승강장 진입 18 km/h 이하
