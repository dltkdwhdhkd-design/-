# 롤러코스터 설계 시뮬레이터

중3 과학 **역학적 에너지 전환과 보존** 단원의 "롤러코스터 설계하기" 수행평가용 프로그램입니다.
레일을 직접 설계하고 열차를 운행해서, 설계가 실제로 작동하는지와 안전한지를 확인할 수 있습니다.

## 실행 방법

설치할 것은 없습니다. `index.html` 파일을 내려받아 크롬·엣지·사파리 같은 웹 브라우저로 열면 됩니다.
(인터넷이 없으면 글꼴만 기본 글꼴로 바뀌고 기능은 모두 동작합니다.)

## 할 수 있는 것

| 기능 | 설명 |
| --- | --- |
| 레일 설계 | 흰 점을 끌어 높이·위치를 바꾸고, 점을 추가·삭제합니다. 구간마다 일반 레일 / 체인 리프트 / 자석 브레이크 / 정거장을 정합니다. 루프도 넣을 수 있습니다. |
| 열차 설정 | 차량 수, 차량 질량, 승객 수·질량을 바꿉니다. 질량을 바꿔도 속력이 같다는 것을 확인할 수 있습니다. |
| 운행 | 열차가 실제로 달리며 속력, 높이, 수직 G, 위치·운동·열·전기 에너지를 실시간으로 보여 줍니다. |
| 에너지 높이선 | 보라색 점선(h + v²/2g). 레일이 이 선보다 높으면 열차는 넘지 못합니다. |
| 그래프 | 이동 거리에 따른 에너지(쌓은 그래프), 속력(이론값과 비교), 수직 G를 보여 줍니다. |
| 안전 검토 | 완주, 첫 언덕이 가장 높은지, 최고 속력, G 범위, 루프 꼭대기, 정거장 진입 속력, 지면 높이를 자동으로 검사합니다. |
| 계산 노트 | 학생이 먼저 위치 에너지와 속력을 계산해 입력하면 오차를 알려 줍니다. 풀이 과정과 지점별 에너지 표도 볼 수 있습니다. |
| 저장 | 설계는 브라우저에 자동 저장되고, 설계 코드를 복사해서 다른 기기에서 불러올 수 있습니다. |

## 수행평가 기준과의 연결

- **과학적 원리 이해**: 에너지 그래프와 에너지 높이선, 계기판의 "위치 에너지 → 운동 에너지" 같은 전환 설명
- **설계의 타당성**: 안전 검토 탭 (레일 길이·높이·곡선·차량 무게·최고 속력과 안전성)
- **계산 및 추론**: 나의 예측 → 풀이 과정 → 지점별 에너지 표
- **[9과22-02] 전자기 유도**: 자석 브레이크 구간에서 운동 에너지가 전기 에너지로 바뀌는 양을 계산합니다.

## 물리 모델

- g = 9.8 m/s², 위치 에너지의 기준면은 지면(높이 0 m)
- 열차는 질량 중심 한 점으로 계산합니다.
- 마찰을 끄면(기본값) 역학적 에너지가 정확히 보존되어 이론값과 시뮬레이션 값이 같습니다.
- 마찰을 켜면 바퀴 마찰(μ × 수직항력)과 공기 저항이 열에너지로 바뀝니다.
- 수직 G = cosθ + v²κ/g (κ: 레일 곡률, 약 4 m 구간 평균)
- 안전 기준(수업용): 최고 속력 120 km/h 이하, 수직 G −1.5 ~ +5.0, 루프에서 뒤집혔을 때 G > 0, 정거장 진입 18 km/h 이하
