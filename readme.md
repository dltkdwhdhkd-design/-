# 천체 시뮬레이터 (중학교 과학 · VR/AR 지원)

중학교 과학 **「태양계」**, **「별과 우주」** 단원을 3D로 직접 움직여 보며 이해하는 웹 시뮬레이션입니다.
설치 없이 웹 브라우저에서 바로 실행되고, **메타 퀘스트 3** 브라우저에서 열면 **VR**(가상 우주 속으로 들어가기)과
**AR**(패스스루로 내 책상 위에 모형 띄우기)로 볼 수 있습니다.

## 들어 있는 시뮬레이션 (11개)

모형의 크기와 거리는 이해를 돕기 위해 실제 비율과 다르게 과장한 부분이 있습니다(화면에 안내되어 있어요).

## 실행하기

### 1) 인터넷 주소로 열기 — GitHub Pages (퀘스트 3에서 쓰려면 이 방법)

VR/AR(WebXR)은 **https 주소**에서만 동작하므로 GitHub Pages로 공개해야 합니다. 컴퓨터에서 한 번만 설정하면 됩니다.

1. 컴퓨터 브라우저로 https://github.com/dltkdwhdhkd-design/-/settings/pages 에 들어갑니다.
   (저장소 위쪽 메뉴의 **⚙ Settings** → 왼쪽 메뉴 **Pages**)
2. **Build and deployment** 의 **Source** 가 `Deploy from a branch` 인지 확인합니다.
3. 바로 아래 **Branch** 에서 `None` 으로 되어 있는 버튼을 눌러
   **`claude/astronomy-simulation-program-1wc4vp`** 를 고르고, 옆 폴더는 **`/ (root)`** 그대로 둔 뒤 **Save** 를 누릅니다.
   > ⚠ `main` 을 고르면 안 됩니다. 지금 `main` 에는 코드가 없고 이 설명서만 있어요. (코드를 `main` 에 합친 뒤에는 `main` 을 골라도 됩니다.)
4. 1~3분 기다린 뒤 같은 Pages 화면을 새로고침하면 위쪽에 **"Your site is live at …"** 이 나타납니다.
5. 그 주소 `https://dltkdwhdhkd-design.github.io/-/` 를 컴퓨터에서 먼저 열어 단원 목록이 보이는지 확인합니다.

진행 상황은 저장소의 **Actions** 탭에서 `pages build and deployment` 항목으로 볼 수 있어요 (초록 체크 ✓ = 성공).

### 2) 내 컴퓨터에서만 열어 보기 (선택 — VR은 안 됨)

인터넷에 올리지 않고 컴퓨터 화면으로만 보고 싶을 때의 방법입니다. **퀘스트 3에서는 이 방법으로 VR을 쓸 수 없어요** (https가 아니기 때문).

1. 코드 내려받기: https://github.com/dltkdwhdhkd-design/-/archive/refs/heads/claude/astronomy-simulation-program-1wc4vp.zip
   (저장소 첫 화면의 초록 **Code → Download ZIP** 은 `main` 을 받으므로 코드가 없습니다.)
2. 압축을 풀고, 그 폴더(`index.html` 이 있는 폴더)에서 명령 프롬프트/터미널을 엽니다.
3. 웹 서버 실행 (파이썬이 설치되어 있어야 해요):
   ```bash
   python -m http.server 8000     # 윈도우에서 안 되면: py -m http.server 8000
   ```
4. 브라우저에서 http://localhost:8000 을 엽니다.

> `index.html`을 더블클릭해서 바로 열면(file://) 화면이 비어 보입니다. 꼭 위처럼 웹 서버로 여세요.

## 메타 퀘스트 3에서 쓰기

1. 퀘스트 3에서 **Meta Quest 브라우저**를 열고 위의 GitHub Pages 주소로 접속합니다. (자주 쓰면 북마크해 두세요.)
2. 시뮬레이션을 하나 고른 뒤 오른쪽 조작판의 **🥽 VR로 보기** 또는 **📦 AR로 보기** 를 누릅니다.
   - **VR**: 우주 공간 속에 모형이 크게 나타납니다.
   - **AR**: 패스스루(실제 방 화면) 위에 작은 모형이 책상 위처럼 나타납니다. 처음에 카메라·공간 사용 권한을 물으면 허용하세요.
3. VR/AR 안에서는 왼쪽 앞에 **조작 패널**, 오른쪽에 **학습 내용** 패널이 떠 있습니다.
   패널의 **☰ 단원 메뉴** 로 헤드셋을 벗지 않고 다른 시뮬레이션으로 바로 넘어갈 수 있습니다.

### 조작법

| 동작 | 컨트롤러 | 손 추적 |
| --- | --- | --- |
| 패널 버튼 누르기, 슬라이더 끌기 | 광선으로 가리키고 **트리거** | 광선으로 가리키고 **엄지·검지 집기(핀치)** |
| 모형 잡아서 옮기기·돌리기 | **그립** 버튼을 누른 채 움직이기 | 패널의 '모형 작게/크게/돌리기' 버튼 |
| 모형 크기 조절 | 두 손으로 그립 후 벌리기/좁히기, 또는 **스틱 위/아래** | 패널 버튼 |
| 모형 회전 | **스틱 좌/우** | 패널 버튼 |
| 패널 옮기기 | 패널을 가리킨 채 **그립** | - |
| 패널 숨기기/보이기 | **A / X** 버튼 | - |
| 내 앞으로 다시 배치 | **B / Y** 버튼 또는 패널의 '다시 배치' | 패널 버튼 |
| 나가기 | 패널의 '나가기' 또는 퀘스트 메뉴 버튼 | 패널 버튼 |

### 수업 활용 팁

- **시차의 원리**: VR에서 '왼쪽 눈만', '오른쪽 눈만', '번갈아 감기'를 눌러 보세요. 실제로 한쪽 눈 화면이 까맣게 가려집니다.
  AR로 하면 내 방의 물건이 먼 배경 역할을 합니다.
- **달의 위상 변화**: VR/AR에서 학생이 그 자리에서 천천히 한 바퀴 돌면서 달을 따라 보게 하세요. 공과 전등으로 하는 실험과 같습니다.
- **별의 일주 운동**: 위도를 북극(90°) → 서울(37.5°) → 적도(0°)로 바꾸며 별의 궤적이 어떻게 달라지는지 비교해 보세요.
  '천구 밖에서' 를 고르면 천구 모형을 밖에서 볼 수 있습니다.
- 퀘스트 화면을 TV·노트북으로 **전송(캐스트)** 하면 나머지 학생들도 함께 볼 수 있습니다.
- 퀘스트가 없는 학생은 컴퓨터·태블릿·휴대폰에서 같은 시뮬레이션을 마우스/손가락으로 조작할 수 있습니다.

```

```

## 새 시뮬레이션 추가하기

`js/modules/` 에 파일을 만들고 `js/modules/index.js` 목록에 한 줄을 추가하면 됩니다.
조작 요소를 한 번만 적으면 **컴퓨터용 조작판과 VR 패널이 자동으로 함께** 만들어집니다.

```js
export default {
  view: { layout: 'diorama', radius: 5, camera: { pos: [0, 3, 8], target: [0, 0, 0] } },
  info: `## 제목\n- 설명`,
  create(ctx) {
    const state = { speed: 1 };
    // ctx.root 에 three.js 물체를 추가
    return {
      update(dt) { /* 매 프레임 */ },
      controls: [
        { type: 'slider', label: '빠르기', min: 0, max: 5, step: 0.1, get: () => state.speed, set: (v) => (state.speed = v) },
        { type: 'toggle', label: '보이기', get: () => true, set: () => {} },
        { type: 'readout', label: '값', get: () => '123' },
      ],
    };
  },
};
```

- `layout`: `diorama`(탁자 위 모형), `surround`(나를 둘러싼 공간, 예: 밤하늘), `head`(내 머리가 중심, 예: 달의 위상)
- 조작 요소 종류: `slider`, `toggle`, `button`, `buttons`, `choice`, `readout`, `heading`, `note`
